DBMS Architecture

Cake Castle Database Schema & Entities

Relational Database Management System (DBMS) structure designed by Srika Sarathan for the Cake Castle platform.

TABLE 1: Cake_Inventory

Stores item metadata, flavor profiles, unit prices, and available stock.

cake_id INT PRIMARY KEY, name VARCHAR(100), flavor VARCHAR(50), price_per_kg DECIMAL(8,2), status VARCHAR(20)

TABLE 2: Customers

Maintains client contact records, delivery addresses, and identity keys.

customer_id INT PRIMARY KEY, full_name VARCHAR(100), phone VARCHAR(15), city VARCHAR(50)

TABLE 3: Cake_Orders (Foreign Key Linked)

Captures transactional event logs, weight quantities, total billing, and timestamps.

order_id INT PRIMARY KEY, customer_id INT REFERENCES Customers(customer_id), cake_id INT REFERENCES Cake_Inventory(cake_id), weight_kg DECIMAL(4,2), total_amount DECIMAL(10,2), order_date TIMESTAMP
